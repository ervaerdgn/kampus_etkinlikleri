# Kampüs Etkinlikleri (Sprint 4: Vite, TypeScript, React)

## Dosyalar
- `package.json`: proje adı, komutlar (dev, build) ve paket listesi.
- `package-lock.json`: yüklenen paketlerin tam sürümleri.
- `node_modules/`: indirilen paketler, GitHub'a gitmez.
- `tsconfig*.json`: TypeScript ayarları.
- `vite.config.ts`: Vite ayarları ve React eklentisi.
- `index.html`: tek HTML sayfası, içinde boş `div#root` var.
- `src/main.tsx`: React'i başlatır ve App'i root'a çizer.
- `src/App.tsx`: uygulamanın ana bileşeni, 5 sayfanın hepsi burada.
- `src/App.css`: Sprint 3'ten taşınan stiller.
- `src/index.css`: tüm sayfaya genel stil, bu sprintte boş.
- `src/types/campus-event.ts`: etkinlik tipi (CampusEvent, Category).
- `src/data/events.ts`: 6 etkinliğin tipli verisi.
- `src/utils/filter-events.ts`: arama, kategori filtresi ve id ile bulma fonksiyonları.
- `public/`: olduğu gibi kopyalanan dosyalar (afiş, favicon).
