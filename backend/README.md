# Kampüs Etkinlik API

Express ile yazılmış, etkinlikleri JSON olarak veren REST API.

## Çalıştırma

```
npm install
npm run seed
npm run dev
```

## Ortam değişkenleri

| Değişken | Açıklama |
|----------|----------|
| PORT | Sunucunun portu (varsayılan 3000) |
| MONGODB_URI | MongoDB bağlantı adresi |

`.env.example` dosyasını `.env` olarak kopyala ve kendi MongoDB adresini yaz.
